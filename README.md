## 💻 Project

This repository contains a frontend application for studies `OpenAI`. 
The project's source code is based on the course: [Inteligência Artificial c .NET AI DeepSeek OpenAI e ChatGPT](https://www.udemy.com/course/net-ai-com-aspnet-openai-chatgpt-deepseek-ollama-mcp-gemini-e-grok/) 

This application integrates with the backend: [Dotnet-AI-API](https://github.com/pauloalvesm/dotnet-ai-api) 

## 🚀 Technologies and Tools

This project was developed using the following technologies:

- **Frontend:**  
  - `HTML5`
  - `CSS`
  - `React`
  - `React Router Dom`
  - `React Toastify`
  - `Axios`
  - `Animate CSS`
  - `Vite`
 
## 📌 Technical Decisions

### For a better user experience, I made the following decisions:
- Create the same structure based on the course.
- Add visual improvements.
- I applied elements that are not included in the course to facilitate the use of the application in AI responses.
 
## 💾 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/pauloalvesm/react-ai-study.git

# Navigate to the project folder
cd react-ai-study

# Restore dependencies
npm install

# Run the project
npm run dev
```
